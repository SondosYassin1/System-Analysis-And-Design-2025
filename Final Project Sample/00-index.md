## Document Purpose

This document is a **complete system analysis and design deliverable** for the School Management System (SMS). It demonstrates the end-to-end process of analyzing a business problem, gathering requirements, modeling system behavior, and designing a technical solution — covering every phase of the Software Development Lifecycle (SDLC) from planning through design.

This serves as a reference example of what a final project deliverable should look like in the SA2025 course.

## Document Conventions

- **NFR-XXX** — Non-Functional Requirement identifier

- **US-XXX** — User Story identifier
- **Diagrams** — All diagrams use Mermaid notation for portability
- **Priority levels** — MoSCoW: Must / Should / Could / Won't
